# NIDS Cybersecurity Hub

A collaborative research website built for an English technical writing course at New York City College of Technology (City Tech). The site explores two interconnected cybersecurity threats and presents Zero Trust Architecture as a unified solution.

## Live Site

[https://purellfix.github.io/NIDS-cybersecurity-hub/](https://purellfix.github.io/NIDS-cybersecurity-hub/)

## About the Project

This website was created as part of a team research project for Prof. Ellis. Each team member researched a specific cybersecurity problem and contributed content to the site.

### Research Topics

**Nicolas Komarov — NIDS False Positive Rates**
Network Intrusion Detection Systems generate an overwhelming volume of false alarms in real-world deployments. Research published in IEEE Communications Magazine found that over 92.85% of all false cases in live IDS/IPS systems are false positives, causing analyst alert fatigue and allowing real attacks to go undetected.

**Yao Koumako — Social Engineering Attacks**
Attackers bypass technical defenses entirely by targeting human psychology through phishing, MFA fatigue attacks, and pretexting. The 2023 Verizon Data Breach Investigations Report found that 74% of all breaches involve the human element.

### The Connection

These two problems compound each other. When security analysts are overwhelmed by NIDS false positives, their vigilance degrades — making social engineering attacks significantly more likely to succeed undetected.

### Proposed Solution

**Zero Trust Architecture (ZTA)** — a security framework built on the principle of "never trust, always verify." ZTA addresses both problems simultaneously:
- Micro-segmentation reduces NIDS false positive rates by up to 78%
- Continuous identity verification and hardware security keys eliminate social engineering damage even when credentials are stolen
